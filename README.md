# hxyfront-62011 马术蹄铁修整档案 · 四蹄适配与复查放行

源提示词编号：6

面向马术俱乐部蹄铁师的修蹄工作台。在马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、
修蹄/复查日期、照片备注等记录之上，接入「四蹄适配 → 领料锁定 → 试装双确认 → 放行复查」
全流程，列表、复查提醒、马匹档案和操作履历共用同一份状态（localStorage 持久化，可恢复演示台账）。

## 业务规则

1. **一匹马最多一张未结束适配单**：已有建档/领料/试装/待复查中的单时，不能为同一匹马再建档；复查归档或终止后才能再开。
2. **四蹄齐全才能领料**：左前、右前、左后、右后四个蹄位的「实测尺寸、步态等级、钉位」全部登记后才开放领料。
3. **领出即锁定**：四蹄蹄铁一次性原子锁定到适配单，`可用 = 账面 − 活动单锁定`；复查归档时转实耗扣账面，终止则解锁退回。
4. **重复 / 并发只留先到**：同一单重复请求直接拦截并记履历；多单同时领用在提交瞬间基于最新库存原子判定，后到者看到被占即停待备料。列表页有「同时发出领用」按钮可演示抢领。
5. **尺寸差超过 2 毫米停待备料**：按蹄位选最近型号，容差内优先同类型蹄铁；超差或适用型号被锁都停待备料并给出原因，库存页补料入库（新型号自动登记）后可在详情里重新领料。
6. **换人连续两次确认步态稳定**：先登记试装；蹄铁师不能确认本人的活，两次确认必须换人，任何一次「不稳」清空确认链退回待试装。
7. **改蹄记录即作废放行**：放行后修改任一蹄记录，原放行失效、复查日作废、确认链清空，蹄铁仍锁定；重新换人两次确认后重新放行。复查日按四蹄最差步态重算：正常 42 天 / 轻微异常 21 天 / 明显异常 14 天。

## 页面

- **适配单**：状态筛选（建档中 / 待领料 / 试装确认 / 待复查 / 已结束）、分类与关键词过滤、并发抢领、新建单、详情内完成四蹄录入到复查归档的全部操作。
- **复查提醒**：逾期、7 天内到期、停待备料、待试装/待第二次确认，点击直达适配单。
- **马匹档案**：左右前后蹄对比、异常步态标记、当前蹄铁与换蹄铁履历。
- **库存与履历**：型号账面/已锁/可用与锁定方、补料入库、全局事件流水。
